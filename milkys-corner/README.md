## Milky's Corner

Cute, cozy, pastel e-commerce style demo built with Next.js, React, and Tailwind CSS.

### Quick start

1. Install deps:
   ```bash
   npm install
   ```
2. Run dev server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000`

### Tech
- Next.js App Router
- React 18
- Tailwind CSS
